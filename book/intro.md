## Project Overview

This project aims to build a structured corpus of scientific publications collected from arXiv. The collected data serves as the foundation for subsequent parsing, standardization, and reference-matching tasks.

The project consists of three milestones:

- **Milestone 1 — Data Crawling:** Collect the source files, metadata, and references for all versions of the assigned arXiv papers.
- **Milestone 2 — Hierarchical Parsing and Standardization:** Parse and standardize the collected LaTeX documents.
- **Milestone 3 — Reference Matching Pipeline:** Develop and evaluate a machine learning pipeline for reference matching.
